================================================================================================
ECDSA two-predictor subset-attack complexity
================================================================================================

Definition of a CLEAN signature:
  • ML predictor correctly recovers the first two decimal digits of k
  • Magnitude predictor (given those correct digits) recovers the true
    decimal length of k

  p_b  = ML accuracy          (swept 80 … 99 %)
  p_m  = magnitude accuracy   (82.00 %)  [conditioned on correct digits]
  p_clean = p_b * p_m         (correlation p = +0.00)

Combinatorial model:
  m_req   = ceil(ceil(curve_bits / L) * safety_factor)
  T_filt  = ceil(surplus * m_req / p_clean)
  clean   = round(p_clean * T_filt)
  runs    = C(T_filt, m_req) / C(clean, m_req)
  time    = runs * t_per_run_sec / cores

curve_bits     = 256
leak_bits (L)  = 6
safety_factor  = 1.3
surplus        = 2.0
t_per_run_sec  = 2.0000 s   (calibrate per hardware; pass --t-per-run-sec)
cores          = [1, 8, 64, 124]
